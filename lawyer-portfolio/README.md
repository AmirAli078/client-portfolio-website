# Lawyer Portfolio (HTML/CSS/JS)
IntelliJ mein: File > Open > is folder ko select karein. index.html par right-click > Open in > Browser.

## Client ki info badalne ke liye
- Naam, text, phone, email: index.html
- WhatsApp number: js/script.js (WHATSAPP_NUMBER) aur index.html mein "923001234567" search karke replace karein
- Facebook / Instagram / LinkedIn links: index.html mein "yourpage" replace karein
- Photo: images/profile.svg ko apni photo se replace karein (profile.jpg rakhein to index.html mein path badal dein)
- Certificates: images/cert-*.svg ko asli scans se replace karein
- Colors: css/style.css ke top mein :root variables
